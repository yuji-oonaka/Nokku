# ⭐ お気に入り (Favorites) モジュール詳細

## 核心ロジック: ``FavoriteController``
 に基づく実装事実。

### 1. トグル・メカニズム
* **単一エンドポイント:** ``toggle()`` メソッドを使用し、既存なら削除、未登録なら追加を同一アクションで行う。
* **レスポンス:** フロントエンドの即時反映（UIの星マーク切替）のため、常に最新の ``is_liked`` 状態を返却する。

### 2. 表示ロジック
* **ランキング/人気順への布石:** ``index`` 取得時に ``withCount('favoritedBy')`` を行い、そのグッズが合計何人に「いいね」されているかを同時に取得する。

### 🚩 地雷注意
* **リレーション名:** モデル上は ``favorites`` ではなく ``favoritedBy`` (Product側) や ``favorites`` (User側) という命名の揺れに注意。
