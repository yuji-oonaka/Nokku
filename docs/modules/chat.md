# 💬 チャット (Chat) モジュール詳細

## 核心ロジック: `ChatService`, `EventChatController`

### 1. ポイント消費のライフサイクル
* **メッセージ送信**: 最初の10通は無料。11通目から `MESSAGE_COST (5pt)` を消費。
* **ルーム作成**: `ROOM_CREATION_COST (50pt)` を消費。
* **安全性**: 全ての消費は `PointService` を経由し、原子性が保証されている。

### ✅ 解決済みの懸念 / 既知の挙動
* **スパム防止**: 5秒以内の連投は `SPAM_DETECTED` エラーを返却し、ポイントは消費されない。
* **失敗記録**: 消費失敗時も `UserChatLog` に `STATUS_FAILED` として記録され、監査が可能。

### ⚠️ 今後の課題
* **無料枠の排他制御**: 超短時間の同時リクエスト時、無料枠を数通分超過して利用できる可能性がある。厳密な制御が必要な場合は、判定処理のロックを検討。
