# 💬 チャット (Chat) モジュール詳細

## 核心ロジック: `ChatService@consumeMessage`
 に基づく実装事実。

### 1. ポイント消費の二段構え
* **無料枠:** `FREE_LIMIT = 10`。同一ユーザー・同一ルーム内の成功ログが10件未満なら消費ゼロ。
* **有料枠:** `MESSAGE_COST = 5`。11件目から `PointService` を呼び出し。

### 2. スパムガード
* `SPAM_INTERVAL = 5` 秒以内の連投は `SPAM_DETECTED` 例外を投げ、DBに `STATUS_FAILED` を記録する。

### 🚩 地雷注意
* **未実装の謎:** `api.php` にある `consume-room`（ルーム作成時の課金）が現状のコードには存在しない。ルーム作成機能を実装する際、`ChatService` にロジックを追加し忘れると「無料で作られ放題」になる。
* **ログ肥大化:** 1発言ごとに `user_chat_logs` が作られるため、大規模イベント時はこのテーブルが最も重くなる。インデックス設計に注意。
