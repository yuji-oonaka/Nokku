# 📢 お知らせ・タイムライン (Announcements) モジュール詳細

## 核心ロジック: ``PostController``
 に基づく実装事実。

### 1. 配信・閲覧コンセプト
* **公式発信限定:** 管理者(Admin)およびアーティスト(Artist)からファンへの一方通行な「お知らせ」として運用。
* **配信ターゲット:** * 管理者の投稿：フォロー関係を問わず、**全ユーザー**のタイムラインに表示。
    * アーティストの投稿：そのアーティストを**フォローしているユーザー**に表示。

### 2. 厳格な公開制御
* **未来・過去の隠蔽:** 一般ユーザーには ``publish_at`` 以前、または ``expires_at`` 以降の投稿は API レベルで完全に除外される。
* **プレビュー権限:** 投稿者本人の場合は、公開期間外であっても表示される（リハーサル・アーカイブ用）。

### 🚩 地雷注意
* **全件配信のリスク:** 管理者の投稿はフォローフィルタを通らない。全ユーザーに通知されるため、テスト投稿等の運用ミスに細心の注意を払うこと。
