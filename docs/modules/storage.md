# 🖼️ ストレージ・物流 (Storage & Assets) モジュール詳細

## 核心ロジック: ``ImageUploadController``
 に基づく実装事実。

### 1. 中央集約型のフォルダ管理
* **振分ロジック:** リクエストの ``type``（product, event, avatar, post）に応じて、自動的に保存先フォルダを ``products/``, ``events/`` 等に振り分ける。
* **公開設定:** 全ての画像は ``public`` ディスクに保存され、即座にアクセス可能な URL が生成される。

### 2. 安全なアップロード
* **バリデーション:** ``StoreImageRequest``（未精査だがControllerの記述より推測）により、ファイル形式とサイズが制限されていることを前提とする。

### 🚩 地雷注意
* **自動クリーンアップの欠如:** このControllerは「保存」のみを担当する。レコード削除時（例：投稿の削除）の「ファイルの物理削除」は、Observer や各Controller側で責任を持つ必要があることに注意せよ。
* **asset()関数の依存:** URL生成に ``asset()`` を使用しているため、``.env`` の ``APP_URL`` 設定が正しくないとフロントエンドで画像が表示されない。
